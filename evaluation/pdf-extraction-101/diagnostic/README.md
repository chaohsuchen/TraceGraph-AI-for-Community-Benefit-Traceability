# 三份原始 PDF 的承诺抽取诊断

2026-11-25。范围是从受信 PDF 发现承诺到生成可检索候选。采用同三份 PDF、同 101 个 Golden 正例和同一份计分代码，从头回放现有结果。此实验没有修改应用、数据库、履约 verdict 或既有正式分数。

## 分歧复核具体做了什么

第一次来源回放让 GPT-5.4 分段读取三份 PDF 的全部 32 个窗口。每个窗口对既有候选给出分类和依据，再检查本窗口漏掉的可追踪项目。模型读取 258 个冻结候选，提议 34 个有原文定位的新候选。这两个任务在同一个调用中完成。模型未取得 Golden、旧复核结论、匹配结果或联网工具。

看到第一轮筛选与补抽的取舍后，设计第二轮裁决。这是同模型、不同提示词的复核，使用新的上下文。它读取两轮意见不一的 90 个旧候选和全部 34 个补抽候选，共 124 个。输入包括候选、引文、附近原句和章节。它保留 63 个，按原文限定措辞后保留 13 个，归档 48 个。第二轮仍未向模型提供 Golden。两轮都同意的旧候选不重复调用，因此 H023 这类两轮一致漏判的案例仍会漏掉。

所有政策都用旧目录里已确认的归并 ID。先冻结输出，再在本机调用相同评分函数。每个匹配要求同一文件、引用并集覆盖至少半段 Golden 引文，并执行一对一分配。附加的严格位置检验还要求交并比至少 0.5，命中从当前 41 增到 54；该检验同样无法判断语义。共记录 57 个 API 请求，含首轮结构校验重试，使用 185,796 个输入 token 和 44,849 个输出 token。未调用联网搜索。

## 对新增与剩余差距的复查

逐条阅读最终方案新增的 19 行 Golden 陈述与其匹配预测。17 个配对覆盖核心事实。A011 的匹配预测只写了 30 天期限，金额在另一个保留候选里；H024 的匹配预测只写了 Flushing SkyPark，另一个保留候选记录了 Corona 的 450 套可负担住房。该复读检查的是匹配陈述，未进行独立人工双标。这 19 个位置命中也不能解释为 19 项全新义务，例如 A041、A043 早已有更笼统的交通承诺，A055 与 A048 有内容重叠。

剩余 20 行中，选址报告占 15 行，RFA 占 5 行。11 行位于选址报告第 24–28 页。可继续挖掘的项目包括 A032 的薪酬估计，以及 A006、A009 包在投标要求中的 30% 目标。A035 已被补抽识别，但复核将已披露的住房合作方视为背景。适合让这种关系作为项目旁证保留，同时保留来源。H023 可记为监管机构对 food hall 义务的判断，避免把它写成已生效的牌照条款。A031 和重复的 A019 分别涉及建模粒度和注释重复，继续检索也无法单独解决。

旧 B0 在这 20 个剩余位置中命中了 10 个。其冻结的 446 个输出按本口径共命中 60 个。可测试把 B0 抽到、当前模型未覆盖的原文段落交回同一来源复核，而直接合并全部 B0 输出会把原来的流程噪声一并带入。上述 10 个是可定位的候选机会，没有把它们计入 81。

## 建议的落地顺序

1. 在现有 PDF 入库路径接上来源内补抽和分歧复核，沿用已有的引文和 ID 校验。保存采纳、改写或归档的理由。
2. 在写数据库前处理同义归并、字段补全和独立子义务。对已有目录匹配到相同义务时追加引文，保留原 ID 和研究历史。仅由可靠 PDF 发现的新记录进入未研究状态。
3. 保留一组固定语义回归案例。H010、H014 要保留计划措辞，H013 要保留监管建议，A011 要同时显示金额与期限，A030/A031 可独立追踪，H019/H020 不能互相得分。另选未参与设计的 PDF 验证后，再决定是否扩大默认补抽范围。
